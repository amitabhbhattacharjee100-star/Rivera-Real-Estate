# COMP100 Python Programming Exercises

## Overview
This directory contains Jupyter Notebook exercises for COMP100 - Introduction to Programming with Python. These exercises are designed to help students learn fundamental programming concepts through hands-on practice.

## Exercise Files

### Introduction & Basics
- **ex01_intro.ipynb** - Introduction to Python variables and built-in functions
- **ex02_data_types.ipynb** - Working with Python data types (None, strings, numbers, booleans)

### Control Structures
- **ex03b_if_statements.ipynb** - Conditional statements and decision making
- **ex03c_match_statements.ipynb** - Pattern matching with match statements

### Loops
- **ex04a_while_loop.ipynb** - While loops and iteration
- **ex04b_for_loop.ipynb** - For loops and sequence iteration

### Functions
- **ex05_functions.ipynb** - Defining and using functions, parameters, and return values

### Data Structures - Sequences
- **ex06a_string.ipynb** - String manipulation and methods
- **ex06b_tuple.ipynb** - Working with tuples
- **ex06c_list.ipynb** - List operations and methods
- **ex06d_sequence.ipynb** - General sequence operations

### Data Structures - Collections
- **ex08a_set.ipynb** - Set operations and methods
- **ex08b_dict.ipynb** - Dictionary operations and methods
- **ex08c_all_collections.ipynb** - Comprehensive collection exercises

### Modules
- **ex10_modules.ipynb** - Importing and using Python modules

### Object-Oriented Programming
- **ex11b_classes.ipynb** - Classes, objects, and methods
- **ex12a_inheritance.ipynb** - Inheritance and class hierarchies

### Demo Files
- **demo11b_classes.ipynb** - Class demonstrations and examples
- **demo12a_inheritance.ipynb** - Inheritance demonstrations and examples

## How to Use

1. **Prerequisites**: Install Python 3.x and Jupyter Notebook
   ```bash
   pip install jupyter
   ```

2. **Launch Jupyter Notebook**:
   ```bash
   jupyter notebook
   ```

3. **Open an exercise file**: Navigate to the exercises directory and open any `.ipynb` file

4. **Complete the exercises**: Follow the instructions in each notebook and write your code in the provided cells

## Learning Path

Your instructor will assign specific exercises based on the course curriculum. However, it's recommended to:
1. Start with introduction and basics (ex01, ex02)
2. Move through control structures (ex03b, ex03c)
3. Practice loops (ex04a, ex04b)
4. Learn functions (ex05)
5. Master data structures (ex06*, ex08*)
6. Understand modules (ex10)
7. Explore object-oriented programming (ex11b, ex12a)

## Tips
- Each exercise explores a small facet of the intended learning concept
- You are encouraged to attempt all questions for maximum understanding
- Experiment with the code - try variations and see what happens
- Use the demo files for additional examples and clarification
